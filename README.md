# JS Recap 1

A collection of small HTML, CSS and JavaScript exercises for recapping web development basics. The pages are also published on the Metropolia server so they can be tested in the browser (links below).

Server base address: https://users.metropolia.fi/~kimtun/Javascript-ohtu/week1/js-recap1/

## Contents

- [`index.html`](https://users.metropolia.fi/~kimtun/Javascript-ohtu/week1/htmlcss_task/), `style.css` – HTML recap page (headings, image, link, table)
- `task1/` – [Temperature converter](https://users.metropolia.fi/~kimtun/Javascript-ohtu/week1/js-recap1/task1/task1.html) (Celsius → Fahrenheit and Kelvin)
- `task2/` – [Distance between two points](https://users.metropolia.fi/~kimtun/Javascript-ohtu/week1/js-recap1/task2/task2.html)
- `task3/` – [Triangle identifier](https://users.metropolia.fi/~kimtun/Javascript-ohtu/week1/js-recap1/task3/task3.html)
- `task4/` – [Course score calculator](https://users.metropolia.fi/~kimtun/Javascript-ohtu/week1/js-recap1/task4/task4.html)
- `task5/` – [Natural number iterator](https://users.metropolia.fi/~kimtun/Javascript-ohtu/week1/js-recap1/task5/task5.html)
- `task6/` – [Multiplication table generator](https://users.metropolia.fi/~kimtun/Javascript-ohtu/week1/js-recap1/task6/task6.html)

Each task folder contains an HTML file (`task1.html`, `task2.html`, ...) and a JavaScript file. Input is collected with `prompt()` and results are shown on the page.

## Usage

Open any of the links above, or open a task's HTML file locally in a browser. No build step is needed.

## Development

Install the dev dependencies (ESLint) with:

```sh
npm install
npx eslint .
```
